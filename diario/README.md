# Súper Diario

Diario personal muy editable que se instala como app en el celular.

- Texto con formato: negrita, cursiva, tachado, resaltador, colores, títulos, citas, listas y casillas
- Cinco letras, cuatro papeles (rayado, cuadros, puntos, liso), colores de papel y de tinta
- Fotos con marco polaroid, cinta, simple o círculo
- Dibujo a mano alzada (lápiz, pincel, marcador, goma) y stickers propios
- Ánimo del día, ubicación, etiquetas, favoritas, búsqueda
- Calendario con racha y "año en píxeles"
- Plantillas, dictado por voz, modo concentración
- Copia de seguridad (.json) y exportación a PDF
- Funciona sin conexión; todo se guarda en el dispositivo

## Publicarlo con GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch `main`, carpeta `/ (root)` → Save.

## Instalarlo
- Android (Chrome): abrir la página → menú ⋮ → "Instalar app" / "Agregar a la pantalla principal".
- iPhone (Safari): Compartir → "Agregar a inicio".
